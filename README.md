# Safe8bit for Homebrew

```bash
brew install --cask chingling123/tap/safe8bit
```

Installs Safe8bit.app in /Applications and the `safe8bit` command line (also as `safebit`).
The vault is free; Safe8bit Pro is sold at [safe8bit.com](https://safe8bit.com/).

The release zips here are signed with Developer ID and notarized by Apple.
